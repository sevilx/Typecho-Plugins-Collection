## 本仓库改动

- 适配目标：Typecho **1.3.1-rc**、PHP **8.2**；全部 PHP 文件通过 `php -l`。
- 保留原文件内的 `@package` / `@author` / `@version` / `@link` 署名注释，未做改名或抹除。
- 入口文件补齐 `if (!defined('__TYPECHO_ROOT_DIR__')) { exit; }` 防护（若原本缺失）。
- 安全加固详见仓库根目录 [SECURITY.md](../SECURITY.md)；涉及本插件的补丁均在代码里以「安全加固」注释标注。

## 使用

复制本目录到 `usr/plugins/PageViews/`，在后台「插件管理」启用；配置说明以插件原有 README 为准。
启用前请备份数据库。

## 2026-11-07 运行时回归修复

- 主题常用 `class_exists('PageViews_Plugin')` 判断插件是否存在；只要文件放进
  `usr/plugins/PageViews/` 就会命中，即使插件未启用。此时 `Helper::options()->plugin('PageViews')`
  会抛 `Typecho\Plugin\Exception: 插件PageViews的配置信息没有找到`，造成全站 500。
- `statisticalPageViews()` / `showPageViews()` 增加 `try/catch (\Throwable)`：未启用时统计静默跳过、
  侧栏降级显示 0；输出统一 `htmlspecialchars(ENT_QUOTES)`，`$views` 强转 `(int)`。
- 专项验证：删除 `plugin:PageViews` 配置后首页与文章页仍 200，无 PHP 报错，
  侧栏显示「总访问量：0次」。
