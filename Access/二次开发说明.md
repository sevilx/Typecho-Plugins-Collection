## 本仓库改动

- 适配目标：Typecho **1.3.1-rc**、PHP **8.2**；全部 PHP 文件通过 `php -l`。
- 保留原文件内的 `@package` / `@author` / `@version` / `@link` 署名注释，未做改名或抹除。
- 入口文件补齐 `if (!defined('__TYPECHO_ROOT_DIR__')) { exit; }` 防护（若原本缺失）。
- 安全加固详见仓库根目录 [SECURITY.md](../SECURITY.md)；涉及本插件的补丁均在代码里以「安全加固」注释标注。

## 使用

复制本目录到 `usr/plugins/Access/`，在后台「插件管理」启用；配置说明以插件原有 README 为准。
启用前请备份数据库。

## 2026-11-07 运行时回归修复

- `Access_Migration::tableExists()` 原先用 MySQL 专用的 `SHOW TABLES LIKE`，SQLite / PgSQL 不兼容；
  改用 `SELECT 1 FROM <表> LIMIT 1` 后，SQLite 驱动仍会输出
  `SQLite3::prepare(): ... no such table` 的 warning 并印进页面 HTML（warning 不是异常，catch 不到）。
- 最终按 adapter 查系统目录表：SQLite → `sqlite_master`，PgSQL → `pg_tables`，
  MySQL → `SHOW TABLES LIKE`；表名经 `/^[A-Za-z0-9_]+$/` 校验；未知适配器降级并抑制驱动 warning。
- 该探测位于 `beforeRender` 钩子的调用链上，每次前台请求都会走到，修复后 20 条路由全部无 PHP 报错。
- 前台 `writeType=1` 统计依赖主题调用 `$this->footer()`；DUX 主题已补齐，换主题前请先确认。
