## 本仓库改动

- 适配目标：Typecho **1.3.1-rc**、PHP **8.2**；全部 PHP 文件通过 `php -l`。
- 保留原文件内的 `@package` / `@author` / `@version` / `@link` 署名注释，未做改名或抹除。
- 入口文件补齐 `if (!defined('__TYPECHO_ROOT_DIR__')) { exit; }` 防护（若原本缺失）。
- 安全加固详见仓库根目录 [SECURITY.md](../SECURITY.md)；涉及本插件的补丁均在代码里以「安全加固」注释标注。

## 使用

复制本目录到 `usr/plugins/PostToc/`，在后台「插件管理」启用；配置说明以插件原有 README 为准。
启用前请备份数据库。

## 2026-11-07 运行时回归修复

- **根因**：原实现把 CSS 注入 `header`、把配置变量与 `script.js` 注入 `footer`；DUX 主题未调用
  `$this->footer()` 时脚本完全不加载，目录「看起来启用了却不出现」。
- `Plugin.php` 改为 `header` 一次性注入 CSS + 配置 + `defer script.js`，`footer` 保留兜底，
  `self::$assetsInjected` 去重；`settings()` 为老站点配置缺失提供默认值并捕获异常。
- 配置输出使用 `JSON_HEX_TAG | JSON_HEX_AMP | JSON_HEX_APOS | JSON_HEX_QUOT`，
  防后台颜色字段闭合 `<script>`。
- `static/script.js` 重写为无依赖、幂等（`AbortController` 撤掉旧监听）、passive + rAF 节流、
  支持 DUX `.article-content`；高亮只切 `.active`，不再写 inline color。
- `static/style.css` 改为 CSS 变量并支持 `data-theme` / `.night` / `prefers-color-scheme` 深色；
  左侧留白不足（1366 / 1440）时加 `.toc-inline` 降级为正文内卡片，不再遮挡文章标题；
  超宽屏仍保留经典悬浮布局并留出 65px 间隙。

> 依赖：主题必须在 `</body>` 前调用 `$this->footer()`，否则 footer 钩子的兜底不会触发。
