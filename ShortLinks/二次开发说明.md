## 本仓库改动

- 适配目标：Typecho **1.3.1-rc**、PHP **8.2**；全部 PHP 文件通过 `php -l`。
- 保留原文件内的 `@package` / `@author` / `@version` / `@link` 署名注释，未做改名或抹除。
- 入口文件补齐 `if (!defined('__TYPECHO_ROOT_DIR__')) { exit; }` 防护（若原本缺失）。
- 安全加固详见仓库根目录 [SECURITY.md](../SECURITY.md)；涉及本插件的补丁均在代码里以「安全加固」注释标注。

## 使用

复制本目录到 `usr/plugins/ShortLinks/`，在后台「插件管理」启用；配置说明以插件原有 README 为准。
启用前请备份数据库。

## 2026-11-07 运行时回归修复

- 新增 `convertHtmlLinks()` / `isConvertibleLink()` / `isInternalUrl()`：只转换站外、绝对、http(s) 链接；
  相对路径、锚点、`mailto:` / `tel:` / `javascript:` / `data:` 一律不动；本站链接按
  host + port + path 前缀判断，不再用 `strpos($link, $siteUrl)` 子串匹配。
- 统一用 `preg_replace_callback()` 改写 `<a>`，支持单/双引号 `href`；追加 `target="_blank"` 时必补
  `rel="noopener noreferrer"`，已有 `target` / `rel` 不重复。
- 修复 `fieldsConvert()` 使用未定义 `$text`（自定义字段转换一直是死代码）、`autoLink()` 强力模式
  条件写反且读错 options；强力模式跳过已有 `<a>` / `<pre>` / `<code>` / HTML 标签 / Markdown `](...)`。
- 删除 `authorPermalinkTarget`：原实现往评论者 URL 拼接 `'" target="_blank'`，会被 Typecho 1.3 的
  `Common::safeUrl()` 与主题转义破坏；评论者链接现在只转 `/go/`，新窗口行为交回主题。
- `textareaToArr()` 丢弃空行，修复白名单空行使 `strpos($url, '')` 恒命中、导致全量放行的问题。
- `Action.php`：占位符输出统一 `htmlspecialchars(ENT_QUOTES)`；referer / nullReferer 空值兜底；
  无跳转页时直接 301，不再对目标做 `htmlspecialchars_decode()`。
- 新增 `tools/shortlinks_test.php`，44 例纯逻辑单测（无需安装 Typecho）。
